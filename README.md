# ONVIF AI Bridge – Home Assistant add-on

Makes camera AI detections (e.g. Milesight human/vehicle "Advanced Motion
Detection") visible to NVRs that only understand plain ONVIF motion events,
such as the Ajax NVR. See [onvif_ai_bridge/DOCS.md](onvif_ai_bridge/DOCS.md).

Add this repository in Home Assistant: Settings → Add-ons → Add-on store → ⋮ →
Repositories → `https://github.com/taugusti/ha-onvif-ai-bridge`.
